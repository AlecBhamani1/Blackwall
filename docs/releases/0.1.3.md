# Blackwall 0.1.3

This version contains the build originally published to the main channel on September 24, 2026.
The versioned release uses the same application files and updater signatures; no rebuild is involved.

## Changes

- Guided model setup and saved connections, with detection of local Ollama and LM Studio.
- Persistent, host-approved computer pairing with matching-code confirmation, reconnect, and device removal.
- SQLite conversation and attachment storage, with recovery for interrupted saves.
- App locking, Keychain recovery, and cancellation of guest and agent work when locking.
- Agent tools with approvals, local memory, user-managed skills, and independent guest invitations.

## Downloads

Use the `aarch64.dmg` installer for Apple Silicon or the `x64.dmg` installer for Intel Macs.
Existing installations continue to receive update information through the original feed.

## Acceptance status

Automated UI, Rust, dependency-policy, and relay-container checks passed for the published source.
Native signed-upgrade/Keychain acceptance, clean-machine installation, physical two-Mac networking
and sleep testing, hosted-relay operations, and private beta acceptance remain open. Updater
signatures authenticate updates; they do not establish Apple Developer ID signing or notarization.
This development build is not a declaration that public-release acceptance is complete.
